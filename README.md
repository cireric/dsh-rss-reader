# @dsh-external/dsh-rss-reader

**在 DSH Web GUI 里读 RSS/Atom 的 Google Reader 式阅读流** —— 订阅源列表 + 跨源条目流 +
未读态 + 完整键盘流。不是「每日 digest 注入提示词」那一类。

- **键盘优先**：`j/k` 换条目、`n/p` 扫视、`空格`/`d` 翻页、`u` 左栏显隐、
  `shift+n/p` 左栏移动光标 + `shift+o` 打开、`o` 展开、`V` 读正文、
  `v` 开原站、`s` 星标、`m` 已读、`A` 全部已读（带 5 秒撤销）、`1/2` 切密度、`f` 订阅管理。
  记不住就按 **`?`**（或点头部最右端的 **`?`**）—— 全部键位在帮助浮窗里，浮窗内容逐行来自
  `src/keys.ts` 的 `READER_KEY_HELP`，与实现由单测互锁（见 AGENTS.md「完成定义」）。
- **正文抽取**：按需抓原站页，识别正文容器后抽成结构化块（段落/标题/代码/图片/列表/引用），
  自动滤掉站点头像与页脚二维码。原文想看原样就开新标签页。
- **跨源重复提示**：同一篇原文出现在多个订阅源时，列表里标出「另有 N 个来源」，可展开看每条来自哪个源
  （只提示、不合并 —— 每个源仍保留自己的 id、已读与星标）。
- **阅读进度**：已缓存正文的阅读位置按「条目 + 正文内容标识」记住，切走再回来接着读（滚动本身不写盘）。
- **阅读偏好**：正文页的 **Aa** 面板调字号 / 栏宽 / 主题（默认跟随宿主），与视图记忆一起持久化；
  标题旁给出「约 N 分钟（估算）」——按**已缓存正文**的中英混排速率估算，不改排序、不改已读状态。
- **本地搜索**：按 `/` 聚焦搜索框。按时间倒序搜索标题、摘要和已缓存正文。可以筛选订阅源、文件夹范围、标签、已读状态、星标和日期。搜索本身不联网、不标读。
  现有 v1 数据库可直接搜索。遇到搜索线程加载失败时，可退出搜索继续阅读，修复插件文件后重新提交查询。
- **文件夹导航**：左栏按订阅分组并汇总文件夹未读数。点击文件夹或用 `Shift+O` 展开和折叠；文件夹旁的 `↗` 按钮进入文件夹浏览（`Tab` 可达、`Enter` 打开）。
- **订阅管理**：OPML 导入导出（导入前逐源抓取校验，坏源逐条列原因）、加源、退订，以及文件夹创建/改名/删除与订阅移动（删除只解除分类，不退订）。
- **标签**：文章可加多个标签；左栏标签行用于浏览/筛选，列表与正文共用同一标签栏。标签只分类，改名保留关联，删除标签不删除文章，也不改变已读、星标或保持未读。
- **保留策略**：按源裁剪（星标不自动删）、正文缓存限量、显式清理旧条目，**不设常驻定时器**。
- **安全**：出网地址策略（协议白名单 + 内网拦截 + 解析层拦截 + 重定向每跳复核）。

## 安装

```bash
dsh plugin --profile web add link:/绝对路径/dsh-rss-reader
```

本包**尚无锁文件**：依赖由 `scripts/build.sh` 从 dsh 源码 checkout 现链（不联网安装），
因此不适合独立安装。仓库内开发见下。

## 开发

```bash
npm run build            # host：链接依赖 + tsc → lib/
npm run build:client     # client：tsdown → lib/client.js（改过 src/client/** 必跑）
npm run typecheck        # 两个工程：host + client
npm test                 # 单元/集成 + 真实 DOM 接线
npm run mutation         # 变异门槛：默认并行 gate（整轮 ~3min 量级，副本自动建在 /tmp；
                         # K/套件并发/子进程堆上限都按宿主资源设闸，见 docs/pitfalls.md §1.10）
npm run mutation:calibrate # 刷新 judges 快照（fast 的映射过期时重跑；快照收 docs/superpowers/plans/2026-10-15-judges-dump.json）

bash scripts/gate.sh      # L1 一键门禁：build → build:client → typecheck → test，逐条打印退出码
```

改代码前先扫一遍 [docs/pitfalls.md](docs/pitfalls.md) 的标题 —— 构建与测试的三个坑都在那里。
构建依赖从哪来、怎么在空目录里复现、为什么没有锁文件：见 [docs/ops/build-reproducibility.md](docs/ops/build-reproducibility.md)。

| 目录 | 内容 |
|---|---|
| `src/` | host 半：抓取 / 解析 / 自持存储（SQLite）/ 抽取 / HTTP 端点（tsc → `lib/`） |
| `src/client/` | 浏览器半：React 组件 + 状态 store（tsdown → 单文件 `lib/client.js`） |
| `docs/pitfalls.md` | **踩坑与开发经验**：工程流程 / 测试夹具 / React / 宿主平台 / 数据解析 / 产品决定 |
| `docs/ops/backup-restore.md` | **备份与恢复操作说明**：停写窗口 / WAL 快照 / 校验器 / 回滚 / OPML 导出范围 |
| `docs/ops/build-reproducibility.md` | **依赖盘点与干净目录复现**：checkout 依赖表 / 各层退出码 / 锁文件方案 |
| `docs/feature-status.md` | **功能状态**：每条能力的状态、源码落点与证据等级（发布前必看） |
| `docs/google-reader-feature-spec.md` | 功能基准：§5「不变量」是复刻时最容易踩错的地方 |
| `AGENTS.md` | 仓库规则、完成定义、工作约定（给 agent 看） |

数据落**插件自持**存储目录 `$DSH_HOME/storages/rss-reader/`（权限 0700）：

| 文件 | 内容 |
|---|---|
| `rss.db` | 条目库、标签关联、阅读进度与链接键（`node:sqlite`；DDL 在 `src/storage/db.ts`，v1/v2/v3 旧库启动时自动升级到 v4） |
| `config.json` | 订阅源、文件夹目录与视图偏好 |
| `reader-YYYY-MM-DD.log` | 刷新日志（按天分文件，保留 14 天；UTC 日期） |

订阅的唯一真相是 `config.json`：它不在（而库里还有条目）时装载**响亮失败**，不会静默给出空面板。
存储域年代的老文件 `$DSH_HOME/storages/rss_reader.json` 与那次一次性迁移**都已下线**（迁移已跑完、
老文件已删），代码里没有任何路径再读它。日志路径曾在 `state/dsh-rss-reader/reader.log`，
自持后不再写那个文件。

## 配置

在 DSH 的插件设置里改，字段与默认值见 `src/config.ts`。常用几项：

| 字段 | 默认 | 说明 |
|---|---|---|
| `feeds` | `[]` | 订阅源**种子**，仅首次落库（幂等）。订阅的真相在 `config.json` 里 |
| `refreshOnStart` | true | 装载时刷新一次 |
| `maxItemsPerFeed` | 500 | 每源保留条目数 |
| `cleanupAfterDays` | 30 | 「清理旧条目」的天数阈值 |

## 键盘

| 键 | 动作 |
|---|---|
| `j` / `k` | 列表页：移动选中（不标已读）；正文页：切上/下一条文章（显示即已读） |
| `n` / `p` | 扫视：滚动视野但**不改变选中** |
| `空格` / `shift+空格` | 整屏翻页 |
| `d` / `shift+d` | 半屏翻页（下 / 上）。`shift+d` 于 2026-10-10 接盘原本 `u` 的上半页 |
| `u` | 左栏（订阅导航）显隐（GR 原义，2026-10-10 由「向上半页」归还） |
| `shift+n` / `shift+p` | 在左栏导航里上下移动**光标**（虚拟视图三行 + 订阅源）——只走高亮，**不改变右栏** |
| `shift+o` | **打开**光标所在行（= 点击它）：虚拟视图行 → 切该过滤，文件夹/源/标签行 → 选该范围 |
| `o` | 展开/折叠选中条目并标已读 |
| `V` / `v` | `V` 在阅读器内读正文；`v` 用系统浏览器打开原站 |
| `s` / `m` / `A` | 星标 / 切换已读 / 全部已读（5 秒撤销） |
| `1` / `2` | 展开视图 / 紧凑列表 |
| `r` / `R` | 刷新未读计数（只重取本地视图，**不抓取**） |
| `/` | 聚焦本地文章搜索 |
| `f` / `F` | 订阅管理（OPML 导入导出、加源、退订） |
| `Esc` | 帮助浮窗开着 → 只关浮窗；正文 → 列表；订阅管理 → 列表 |
| `?` | 快捷键帮助浮窗（开 / 关）。头部最右端那个 `?` 按钮与它等价 |
